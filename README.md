# 🛒 E-Commerce Customer Churn Analysis | MySQL

**Turning Customer Data into Actionable Business Insights.** 📊

## 📌 About the Project
This project explores customer churn in the e-commerce industry using **MySQL** to analyze customer behavior, purchase patterns, satisfaction levels, and payment preferences. It transforms raw customer data into meaningful insights that can help businesses understand customer attrition and improve retention strategies.

## 🎯 Project Objectives
- 🧹 **Data Cleaning:** Handle missing values, outliers, and inconsistent data.
- 🔄 **Data Transformation:** Rename columns and create meaningful customer status categories.
- 📈 **Customer Analytics:** Analyze churn rates, tenure, cashback, coupons, and order behavior.
- 💳 **Payment Insights:** Identify popular payment modes and customer preferences.
- 📦 **Returns Analysis:** Combine customer and return data to investigate churned customers who raised complaints.

## 🛠️ Tech Stack
- **Database:** MySQL
- **Language:** SQL
- **Techniques:** Data Cleaning, Aggregation, Filtering, Subqueries, `CASE` Statements, and Joins

## 💡 Key Outcomes
- Identify churned and active customers.
- Discover patterns in customer complaints and satisfaction.
- Explore purchasing behavior across city tiers and product categories.
- Analyze payment preferences, cashback, and coupon usage.
- Support data-driven customer retention decisions.

## 🚀 Project Goal
To demonstrate practical SQL skills by converting raw e-commerce data into structured analysis that supports smarter business decisions and stronger customer relationships.
